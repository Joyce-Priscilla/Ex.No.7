### EXP 7 : Exploration of Prompt Engineering for Technical Communication

## Date : 27.08.2026
## Reg.No : 212223060107

#### Aim:

To explore various prompt engineering techniques for creating technical communication content using AI models. The goal is to understand how different prompts can be used to generate and improve technical reports, research abstracts, literature reviews, project proposals, resumes, LinkedIn profiles, and research posters.

#### Procedure:

1. **Understanding the Basics of Prompt Engineering:**

   * Familiarize yourself with AI-based tools such as **ChatGPT, Google Gemini, Microsoft Copilot**, or other generative AI tools.
   * These tools can generate technical and professional content based on the instructions provided through prompts.
   * Understand how prompt structure, context, tone, length, and formatting requirements affect the generated output.

2. **Creating a Technical Report:**

   * Use prompts to generate a structured technical report on a selected engineering topic.
   * Specify the required sections such as introduction, objectives, methodology, results, and conclusion.

**Example Prompt:**

`"Create a technical report on a cloud-based network monitoring system. Include introduction, objectives, methodology, implementation, results, advantages, limitations, and conclusion. Use formal technical language."`

3. **Creating a Research Abstract:**

   * Generate a short and precise abstract describing the research problem, methodology, results, and conclusion.

**Example Prompt:**

`"Write a 200-word research abstract on AI-based network health monitoring. Include the problem statement, proposed methodology, key results, and conclusion in formal academic language."`

4. **Creating a Literature Review:**

   * Use AI to organize existing research into major themes and identify limitations and research gaps.
   * Provide the research topic and specify the expected academic style.

**Example Prompt:**

`"Prepare a literature review on cloud-based network monitoring systems. Discuss existing approaches, compare their advantages and limitations, and identify important research gaps."`

5. **Creating a Project Proposal:**

   * Generate a project proposal by providing the project title and requirements.
   * Include problem statement, objectives, methodology, technologies, expected outcomes, and future scope.

**Example Prompt:**

`"Prepare a project proposal for a cloud-based digital twin framework for predictive network health monitoring. Include problem statement, objectives, methodology, technologies used, expected outcomes, and future scope."`

6. **Creating a Resume:**

   * Provide educational qualifications, technical skills, projects, internships, certifications, and achievements.
   * Use prompting to create a professional and concise resume.

**Example Prompt:**

`"Create a one-page professional resume for an engineering student. Highlight education, technical skills, projects, internships, certifications, and achievements. Use simple, concise, ATS-friendly language."`

7. **Creating a LinkedIn Profile:**

   * Generate a professional LinkedIn headline and About section.
   * Include relevant skills, projects, interests, and career goals.

**Example Prompt:**

`"Create a professional LinkedIn profile for an engineering student interested in embedded systems, cloud computing, computer networks, and semiconductor technologies. Write a concise headline and an engaging About section."`

8. **Creating a Research Poster:**

   * Generate concise content suitable for displaying a research project.
   * Include title, problem statement, objectives, methodology, results, conclusion, and future scope.

**Example Prompt:**

`"Create concise research poster content for a project on predictive network health monitoring. Include title, problem statement, objectives, methodology, results, conclusion, and future scope using short points."`

9. **Iterative Prompting for Improvement:**

   * Review the first AI-generated output and identify areas that need improvement.
   * Provide additional prompts to improve grammar, technical accuracy, readability, and originality.
   * Repeat the process until the desired quality is obtained.

**Example Improvement Prompts:**

* `"Correct all grammatical and spelling errors."`
* `"Improve the technical accuracy of this content."`
* `"Make the content more concise and readable."`
* `"Rewrite this in formal academic language."`
* `"Remove unnecessary repetition."`
* `"Make the explanation easier for an engineering student to understand."`
* `"Improve the structure and flow of the content."`

#### Instructions:

1. **Choose an AI Tool:** Select a suitable generative AI tool such as ChatGPT or Gemini.
2. **Create Basic Prompts:** Start with simple prompts for generating technical content.
3. **Create Detailed Prompts:** Add context, format, audience, tone, word limit, and technical requirements.
4. **Generate Different Documents:** Create a technical report, research abstract, literature review, project proposal, resume, LinkedIn profile, and research poster.
5. **Evaluate the Output:** Check the generated content for grammar, technical accuracy, plagiarism, and readability.
6. **Iterate and Optimize:** Modify the prompts based on the identified problems and regenerate the content.
7. **Prepare the Portfolio:** Collect the improved versions of all documents into a technical communication portfolio.

#### Deliverables:

1. **Technical Report** – A structured report generated and refined using prompts.
2. **Research Abstract** – A concise abstract describing the research work.
3. **Literature Review** – A review of existing research with identified research gaps.
4. **Project Proposal** – A proposal containing objectives, methodology, and expected outcomes.
5. **Resume** – A professional and concise resume.
6. **LinkedIn Profile** – A professional headline and About section.
7. **Research Poster** – A concise visual representation of the research work.
8. **Observations and Insights** – Notes describing how different prompts affected the quality of the generated content.
9. **Optimization Report** – A summary of the prompting techniques used to improve the final outputs.

#### Evaluation:

The generated content is evaluated using the following criteria:

| Criteria               | Evaluation                                                              |
| ---------------------- | ----------------------------------------------------------------------- |
| **Grammar**            | Correct spelling, grammar, punctuation, and sentence structure          |
| **Technical Accuracy** | Correctness of technical concepts and terminology                       |
| **Plagiarism**         | Originality and avoidance of excessive similarity with existing content |
| **Readability**        | Clarity, organization, simplicity, and ease of understanding            |

#### Sample Prompt Experiment:

### Naive Prompt:

This prompt is very general and may produce content that is broad, repetitive, or lacking in technical detail.

**Prompt:**

```text
"Write a project proposal about network monitoring."
```

### Refined Prompt:

A refined prompt provides the topic, purpose, structure, audience, and required technical details. This helps the AI produce more relevant and organized content.

**Prompt:**

```text
"Prepare a formal project proposal for a Cloud-Based Digital Twin Framework for Predictive Network Health Monitoring. Include the problem statement, objectives, existing system, proposed system, methodology, technologies used, expected outcomes, advantages, limitations, and future scope. Use clear and concise technical language suitable for a final-year engineering project."
```

### Iterative Prompt:

After reviewing the generated proposal, an additional prompt can be used to improve it.

**Prompt:**

```text
"Review the above project proposal. Correct grammatical errors, remove repetition, improve technical accuracy, make the content more concise, and maintain a formal academic writing style."
```

### Observation:

* The **naive prompt** produced general information with limited structure.
* The **refined prompt** produced more relevant and organized technical content.
* The **iterative prompt** improved grammar, clarity, technical accuracy, and readability.
* Adding context, audience, format, and specific requirements resulted in better AI-generated content.

#### Conclusion:

By experimenting with different prompt engineering techniques, AI can be effectively used to create various forms of technical communication. A simple prompt provides general content, while a refined prompt with specific context, structure, tone, and requirements produces more relevant results. Iterative prompting further improves grammar, technical accuracy, originality, and readability. Thus, prompt engineering is a useful technique for developing an effective **Technical Communication Portfolio**.
